# Subbit 0.0.5

## 新增

- 花销统计：设置按钮右侧新增统计入口，查看分类花销、花销最高 TOP 5 及订阅 / 买断构成；支持切换币种、周期和费用口径。
- PNG 报告：将费用总览、分类与主要资产导出为简洁的黑白报告图片，保存到本地后即可分享。分类超过 10 项时，图片展示前 10 项。

## 修复与改进

- 默认按账单花销排序，支持切换实际花销并记住选择；报销资产同时显示带删除线的账单金额与实际花销。
- 修复相同导入请求重试仍写入文件、增加版本号及覆盖备份的问题，覆盖资产和汇率导入。
- 资产备份最多保留 3 份：最近 2 份普通备份和 1 份导入前备份；支持查看备份时间、资产数量并预览恢复。
- 同批导入中，同名但不同 ID 的资产也会提示可能重复，确认后才保留为独立记录。

## 数据与统计

已有资产无需迁移。普通保存和备份恢复不会覆盖最近一次导入前备份。统计与报告使用全部当前有效资产，不受列表搜索和分类筛选影响；金额为当前周期折算费用，非历史付款流水。缺少汇率时先补齐汇率再导出。

## English

### New

- Spending statistics beside Settings: category costs, top 5 assets, and subscription / lifetime composition, with currency, period and bill / actual cost controls.
- Export a clean monochrome PNG report with totals, categories and leading assets. Reports show the top 10 categories when there are more than 10.

### Fixes and improvements

- Sort by bill cost by default and remember the selected basis. Reimbursed assets show a struck-through bill amount alongside actual cost.
- Replaying identical asset or exchange-rate imports no longer writes files, increments revisions or overwrites backups.
- Keep at most 3 asset backups: 2 recent versions and 1 pre-import checkpoint. Preview timestamps and asset counts before restoring.
- Detect same-name assets with different IDs within one import batch and require confirmation to keep them separately.

### Data and statistics

Existing assets need no migration. Ordinary saves and restores preserve the latest pre-import checkpoint. Reports include all currently active assets, independent of list filters, and show amortized costs rather than payment history. Add missing exchange rates before exporting.

## 安装与升级 / Installation

- macOS 12+：Apple Silicon 与 Intel 分别下载对应 DMG；Windows 10/11 x64 使用安装 EXE。
- 0.0.2–0.0.4 可通过设置 → 关于 → 检查更新升级；0.0.1 需手动安装。离线模式下先恢复联网再检查更新。
- macOS 应用使用 ad-hoc 签名，尚未 Apple 公证；Windows 尚无发布者签名。首次下载可能出现系统信任提示，Windows 缺少 WebView2 时需要联网安装。
- macOS 12+: choose the Apple Silicon or Intel DMG; Windows 10/11 x64: use the installer EXE.
- Versions 0.0.2–0.0.4 support Settings → About → Check for updates; install manually from 0.0.1. Disable offline mode before checking.
- macOS uses ad-hoc signing without Apple notarization; Windows has no publisher signature. First downloads may show trust prompts. Missing WebView2 requires an internet connection to install.
