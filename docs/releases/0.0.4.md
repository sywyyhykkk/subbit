# Subbit 0.0.4（未发布 / Unreleased）

## 新增

- 域名资产：独立记录域名管理商、周期费用和到期日，支持自动获取并本地保存网站图标。
- 离线模式：停止联网更新和打开外部网络链接，继续使用本地汇率、目录与资产；提供带来源日期的内置法币汇率回退。
- MCP 汇率与目录的本地预览、导入接口，保留冲突检测、备份和重复请求保护。
- 每日成本统计、支付方式筛选，以及独立的 Markdown 更新说明弹窗。
- 数据文件与备份占用空间显示、在系统文件管理器中定位当前数据文件。

## 修复与改进

- 修复菜单栏面板在内容和主题准备好前显示的问题，保留按需创建和销毁。
- 记住筛选与排序选择，明确显示全额 / 部分报销状态。
- 统一更新时间的本地时区显示，优化大小面板的列表、按钮和搜索交互。

## 数据兼容

已有资产无需迁移，费用和日期规则继续沿用。新增域名管理商或 MCP 汇率导入回执后，数据文件需由 0.0.4 或更高版本读取；回退旧版本前使用兼容备份。离线模式独立于资产文件保存。

## English

### New

- Domain assets with registrars, recurring prices, expiry dates and locally saved website favicons.
- Offline mode, dated bundled fiat-rate fallbacks, and local MCP previews/imports for rates and catalogs.
- Daily cost summaries, payment-method filters and a dedicated Markdown release-notes dialog.
- Data/backup file sizes and native file location access.

### Fixes and improvements

- Reveal the tray panel after its initial content and theme are ready, preserving on-demand WebView lifecycle.
- Remember filters and sorting; distinguish full and partial reimbursement.
- Show update timestamps in local time and refine main-window and tray-panel interactions.

### Compatibility

Existing assets need no migration. Files containing new registrar fields or rate-import receipts require 0.0.4 or later; use a compatible backup before downgrading. Offline policy is stored independently of asset files.
