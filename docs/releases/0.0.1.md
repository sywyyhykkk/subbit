## Subbit 0.0.1 · 首个正式版本

轻量、本地优先的订阅与买断软件管理工具，无需账号或自建服务器。

- 菜单栏 / 系统托盘总览，按小时、月、年查看成本及报销抵扣。
- 47 个服务、9 个分类，包含 AWS、GCP、阿里云、Vultr 等云服务器。
- 72 个套餐的美元参考价，按所选币种换算，支持手动修改。
- 中英文界面、深浅色、完整备份导入导出，以及供 Agent 使用的本地 MCP。
- 统一新增资产、成本、套餐、汇率、数据定位等界面用语。

### 下载与安装

| 文件 | 适用系统 | 安装方式 |
| --- | --- | --- |
| `Subbit_0.0.1_macos-arm64.dmg` | macOS 12+，Apple Silicon（M 系列芯片） | 打开 DMG，将 Subbit 拖入 Applications，再从 Applications 启动 |
| `Subbit_0.0.1_macos-x86_64.dmg` | macOS 12+，Intel 处理器 | 打开 DMG，将 Subbit 拖入 Applications，再从 Applications 启动 |
| `Subbit_0.0.1_windows-x64-setup.exe` | Windows 10 / 11，Intel / AMD 64 位 | 双击安装程序，完成安装后从开始菜单启动 |

Mac 可在苹果菜单 → 关于本机中查看芯片类型。两个 DMG 分别构建，每个包仅包含对应架构。

不需要安装 Node.js、Rust 或 Python。Windows 若缺少 WebView2，安装程序会联网安装。GitHub 自动附带的 Source code 压缩包是源码，请选择上表中的安装包。

**首次启动提示：** 本版本尚无 Apple Developer 签名 / 公证或 Windows 发布者签名。macOS Gatekeeper 或 Windows SmartScreen 可能提示无法验证开发者。确认文件来自本仓库后，按系统提供的允许打开流程操作；受组织策略管理的设备可能需要管理员允许。正式版标签不代表已完成代码签名。

### 验证范围

发布流程会运行类型检查、目录校验、价格换算测试、Rust 测试，以及包内 MCP 的目录、版本、导入、重试去重、汇总与备份检查。macOS DMG 会校验磁盘镜像、对应的单一架构内容，并在对应架构的 runner 上运行包内 MCP；Windows EXE 会在 Windows runner 中实际安装，并检查原生窗口能否启动。这些检查不代表覆盖所有系统版本和安全策略。

## English

The first stable Subbit release: a local-first subscription and lifetime purchase tracker with 47 service presets, 72 USD-priced plans, currency conversion, reimbursement, backups, Chinese/English UI and local MCP access for Agents.

- **macOS 12+, Apple Silicon:** download `Subbit_0.0.1_macos-arm64.dmg`.
- **macOS 12+, Intel:** download `Subbit_0.0.1_macos-x86_64.dmg`.
- Check Apple menu → About This Mac for your chip. Open the matching DMG, drag Subbit into Applications, then launch it there. Each DMG contains only its target architecture.
- **Windows 10/11 x64:** download the setup EXE, run the installer, then launch Subbit from the Start menu. An internet connection is needed if WebView2 is missing.
- No Node.js, Rust or Python installation is required. The automatically generated “Source code” archives are not installers.
- The apps are not publisher-signed or Apple-notarized. Gatekeeper or SmartScreen may require confirmation before the first launch; managed devices may require administrator approval.

The release pipeline checks types, catalog data, price conversion, Rust tests, packaged MCP behavior, DMG integrity and the single architecture in each Mac package, with packaged MCP checks on matching Mac runners. It also installs the EXE on a Windows runner and checks that a native window opens. It does not certify every OS version or security policy.
