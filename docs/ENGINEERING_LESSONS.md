# 开发经验

本文从本项目已经发生的问题与修正中提炼工程规则，不保存原始对话。开发新功能前先检查相关条目；修复必须消除原因，而不仅是隐藏现象。本文描述历史教训，当前实现以代码为准。

## L01 macOS 安装包完整，但应用无法打开

- **现象**：0.0.2 经浏览器下载后提示应用「已损坏，无法打开」，尽管 DMG 完整性校验和包内 MCP 检查通过。
- **已确认原因**：当时 `.app` 的资源签名验证失败，缺少完整的应用封装签名；发布验收只检查镜像和可执行文件，遗漏最终 App 的资源签名及下载后的首次启动。更新包的独立签名被当作应用可安装性的充分证据。
- **修正与预防**：保留 `bundle.macOS.signingIdentity: "-"` 的 ad-hoc 配置；DMG 内的 App、更新归档解压出的 App 都执行 `codesign --verify --deep --strict`，签名后不能再改资源。发布验收还要覆盖公开下载、安装和首次启动。
- **边界**：签名完整性通过不等于 Apple 公证。未公证时仍可能出现信任提示；新截图若只有系统提示，先诊断具体包，不能仅凭截图断言本次原因相同，更不能以移除隔离属性替代发布修复。
- **相关实现**：`src-tauri/tauri.conf.json`、`.github/workflows/release.yml`。签名概念见 [Tauri macOS 签名文档](https://v2.tauri.app/distribute/sign/macos/)。

## L02 功能和图标更新导致安装包明显增大

- **现象**：同为 Apple Silicon 的包，0.0.2 一度比 0.0.1 大近三倍；此前通用架构包也引发体积增长。
- **原因**：深浅色原始 PNG 被前端与 Rust 重复嵌入，系统图标资源过大，同时存在重复的网络库依赖；只看功能完成，没有比较资源与产物体积。
- **预防**：设计原图保留在设计目录，运行时使用适当尺寸的压缩资源，About 图和应用图按用途选择尺寸；检查前后端嵌入位置和依赖树，复用兼容依赖。macOS 两种架构分别构建，不擅自回到通用包；比较同平台、同架构的安装包与 App 大小。
- **相关实现**：`src-tauri/icons/`、`src/App.svelte`、`src-tauri/src/lib.rs`、`src-tauri/Cargo.toml`、发布工作流。

## L03 测试隔离路径错误，改到了真实设置和备份

- **现象**：验证目录更新和 UI 时误将日常使用的语言设成英文，并覆盖自动备份；资产记录未改动。
- **原因**：测试使用了错误的隔离路径，没有在写入前确认最终数据位置及 location 指针，认为设置了测试环境就已隔离成功。
- **预防**：为每次试验准备独立 `SUBBIT_CONFIG_DIR` 和合成数据，确认配置、数据、锁、缓存、备份均解析到该目录后再启动。路径不对立即停止；误写后不继续运行以免覆盖更多备份，不猜原值。不要用正常安装实例做写入测试。
- **相关实现**：`src-tauri/src/store.rs`、`scripts/smoke-mcp.py`。

## L04 品牌色和产品图标不能凭印象替换

- **现象**：ChatGPT 被设为绿色，部分多色标志被涂成单色；Google One 使用了 Google Drive、QQ 音乐使用了 QQ 图标，部分服务残留字母占位图。
- **原因**：把单色图标库的品牌色当作最终官方图稿，混淆公司品牌与具体产品，没有逐个核对来源。
- **预防**：选对应产品的官方图稿，保留多色和渐变；用中性底板改善深色可读性，不重新染色图形。记录来源和许可，并查看浅色、深色下的实际列表与选择器。
- **相关实现**：`catalog/icons/`、`catalog/services/*.json`、`src/Icon.svelte`、`src/style.css`。

## L05 布局与文案修复需要覆盖完整界面状态

- **现象**：曾有大块配色、侧边栏、过小字体、滚动区域错位、按钮图标不齐；分类切换让弹窗跳动，列表元素贴边，小面板可见条目不足。
- **原因**：局部布局随内容高度变化，没有统一滚动容器、控件对齐和主次层级，只检查单一窗口或短内容。
- **预防**：延续黑白灰及主面板筛选；复用主题变量、稳定弹窗外框和独立内容滚动。新增控件需检查主窗口 / 托盘面板、长列表 / 空列表、中文 / 英文、深浅色，以及切换分类前后的布局；保留已确认的至少三项列表可见空间。
- **相关实现**：`src/style.css`、`src/App.svelte`、`src/DatePicker.svelte`。

## L06 语言切换不能只翻译固定文案

- **现象**：默认等级名称一度不跟随语言切换；日期选择器及部分界面也曾没有本地化。
- **原因**：把默认名称作为普通字符串保存后直接展示，遗漏了已存默认值和派生状态，而非只缺少一组翻译。
- **预防**：可识别的中英文默认名称通过现有映射随语言显示，自定义名称和金额阈值保持不变。覆盖中文、英文、跟随系统，及保存、取消、重新打开；新增资产默认币种沿用语言规则，不重写已有记录。
- **相关实现**：`src/levels.ts`、`src/App.svelte`、`src/DatePicker.svelte`、`scripts/levels.test.mjs`。

## L07 切换套餐后，参考价变化但金额变空

- **现象**：首次打开能带出人民币金额，切换到另一套餐后只更新美元提示，金额输入框为空。
- **原因**：切换时先清空旧金额，再依赖后续响应式更新回填，没有在选择事件内直接完成金额计算；重复选择等交互可能留下空值。
- **预防**：处理选择事件时明确使用本次新值，统一更新套餐、周期和报价。覆盖首次默认、连续切换套餐、月付 / 年付、切换币种、缺汇率及手动改价；不能只验证独立报价函数。
- **相关实现**：`src/App.svelte`、`src/pricing.ts`、`scripts/pricing.test.mjs`。

## L08 输入校验不能用于计算结果

- **现象**：主面板等级在部分汇率换算后不显示。
- **原因**：等级计算复用了输入金额最多 12 位小数的限制，合法中间结果因精度更高而被拒绝。
- **预防**：输入校验与内部十进制计算分开；中间结果保留精度，展示时再舍入。涉及等级和成本时覆盖换算、报销依据、阈值边界、零值及关闭显示，不用空值掩盖计算错误。
- **相关实现**：`src-tauri/src/model.rs`、`src-tauri/tests/core.rs`、`src/levels.ts`。

## L09 日期推进与桌面链接属于真实交互

- **现象**：价格链接点击无行为；日期组件难用且没有在修改开始日期后带出对应到期日。
- **原因**：网页链接行为没有接通桌面 opener；日期字段关联不完整，只验证字段或预览，没有验证桌面用户实际操作链。
- **预防**：外链使用已注册的 opener；日期计算复用既有工具，按原始锚点处理月末与闰年。覆盖改开始日期 / 周期后回填、自动续期、到期边界和关闭数月后重开；真实 Tauri 行为单独验收。
- **相关实现**：`src-tauri/src/lib.rs`、`src/App.svelte`、`src/dates.ts`、`src-tauri/src/model.rs`。

## L10 重复刷新与过量快照增加分配和常驻数据

- **现象**：未变化的数据库仍每 15 秒完整加载；目录刷新结果和事件又触发重复读取；设置关闭的部分路径保留了整份导入预览。
- **原因**：前端接收了不需要的完整导入回执，多个触发源未合并，预览的生命周期依赖各按钮各自清理。
- **预防**：UI 快照只传需要的字段，完整幂等回执保留在磁盘；复用 `createReloadQueue` 合并刷新，保持文件变更和跨天感知；退出设置统一释放预览。不为小目录新增复杂缓存，不把代码优化等同于已测得内存降幅。
- **相关实现**：`src-tauri/src/view.rs`、`src-tauri/src/store.rs`、`src/reload.ts`、`src/App.svelte`。

## L11 仓库文档不能变成聊天或生成过程归档

- **现象**：图标目录曾将生成和修改提示词作为文本纳入版本控制；本地辅助脚本也含机器路径。
- **原因**：将开发过程产物与可交付源码、必要设计资源混在一起提交，缺少内容边界检查。
- **预防**：提交只包含实现和可复用的工程结论，不包含原始对话、生成提示词、个人路径、真实记录或私钥。保留 MIT、About 和正常署名；已忽略的本地辅助产物按任务范围处理，不自动清理。提交前只审阅并暂存本次文件。
- **相关实现**：`.gitignore`、`design/icons/`、本开发经验文档。

## L12 自定义服务绕过分类与搜索筛选

- **现象**：已添加的自定义服务在新增资产的云存储等每个分类中都显示，搜索也不能排除无关的自定义项。
- **原因**：官方预设与自定义服务分两组渲染，只有预设列表应用了分类和搜索条件，自定义列表仅做了去重。
- **预防**：按自定义服务添加时保存的分类筛选，「全部」中仍可见，并按名称响应搜索；先筛选再去重，避免同名不同分类的记录互相遮蔽。不为修正选择器而迁移或覆盖已有资产字段。多数据源拼接的列表必须逐组检查过滤条件，覆盖分类切换、命中 / 未命中搜索和重复记录，不根据单张截图推断所有自定义服务应统一归类。
- **相关实现**：`src/App.svelte` 中的 `pickerServices`、`customServices`。

## L13 托盘面板首屏白闪

- **现象**：点击菜单栏图标后，面板先显示白色区域，再出现内容。
- **已确认原因**：面板按需创建后立即显示，早于前端读取本地数据和应用主题；初始 HTML 未指定系统主题，默认背景为白色。
- **预防 / 验证**：保留按需创建与销毁，首屏数据（或错误状态）和 DOM 就绪后通知原生窗口显示，同时设置匹配的原生背景。隐藏 WebView 不依赖动画帧回调来完成显示，避免窗口永久隐藏。检查深浅主题、连续开关和失焦销毁；原生播放观察与代码检查分开记录。
- **相关实现**：`src-tauri/src/lib.rs` 的 `show_panel`、`panel_ready`，`src/App.svelte` 的初始化流程，`index.html`。

## 维护方式

仅记录有本项目证据的问题；未确认的根因明确标为待核实。新条目沿用现象、原因、预防、相关实现的结构，合并同类经验。功能开发完成前对照本次涉及的条目检查，不把历史上某次未验证或未发布的状态当作永久规则。
