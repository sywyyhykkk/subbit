# Subbit 0.0.3

目录独立更新、更多常用预设，以及更顺手的桌面体验。

## 新增

- 支持远程服务目录和本地缓存，分类、服务、套餐与图标可独立更新，无需每次发布新版应用。在「设置 → 数据 → 更新目录」手动刷新；离线或更新失败时保留缓存，首次离线使用内置目录。
- 内置目录扩充至 57 个服务、11 个分类。新增设计创作工具 Spine，区分买断与年付；加入游戏、安全隐私分类，以及 Xbox Game Pass、PlayStation Plus、Nintendo Switch Online、1Password、Bitwarden、Proton Pass、WPS、B站大会员和爱奇艺。
- 桌面与 MCP 共用更新后的目录，已有资产的名称、套餐、金额、图标和设置保持原样。

## 改进与修复

- 已添加的自定义服务按添加时选择的分类显示，并遵守搜索条件，不再出现在每一个分类中；「全部」仍可查看所有自定义服务。
- 大小面板的花销等级移至 Subbit 标题旁，精简重复说明，优化列表留白、搜索栏对齐与默认显示空间。
- 默认等级名称跟随中文、英文和系统语言切换，自定义等级名称与金额门槛保持不变。
- 修复切换套餐后参考价变化、每期金额却可能为空的问题，按当前币种、周期和汇率直接回填，保留手动改价。
- 核对服务图标，修正 ChatGPT、Google 系列、Figma、QQ 音乐等图形与配色，保留对应产品的官方颜色和渐变，改善深浅色显示；放大菜单栏兔子图标的可见尺寸。
- 减少未变化数据的重复解析和传输，合并并发刷新；界面不再携带完整导入回执，退出设置时释放导入预览。保留 MCP 修改同步与跨天费用更新。
- 补充 MCP 接入说明：配置后由 Agent 客户端自动启动本地服务，无需手动在终端运行。

## 升级与安装

0.0.2 可从「设置 → 关于 → 检查更新」升级；0.0.1 需手动安装一次新版。更新保留本地资产和设置。

macOS 分别提供 Apple Silicon 与 Intel DMG，支持 macOS 12+；Windows 提供 Windows 10/11 x64 安装包，缺少 WebView2 时会联网安装。macOS App 使用 ad-hoc 签名，尚无 Apple Developer ID 签名与公证；Windows 安装包尚无发布者签名，首次启动可能需要系统安全确认。

## English

### New

- Remote service catalog updates with a shared local cache. Categories, services, plans and icons can be published independently of app releases. Refresh from **Settings → Data → Update catalog**; offline or failed updates preserve the last complete cache, with the bundled catalog as the initial fallback.
- 57 bundled services across 11 categories. Add Spine with lifetime and annual options, Gaming and Security & privacy categories, Xbox Game Pass, PlayStation Plus, Nintendo Switch Online, 1Password, Bitwarden, Proton Pass, WPS, Bilibili and iQIYI.
- Desktop and MCP share the updated catalog without overwriting saved asset names, plans, prices, icons or settings.

### Improvements and fixes

- Saved custom services follow their saved category and the search query in the asset picker, instead of appearing in every category. All still includes every custom service.
- Spending levels sit beside the Subbit title in both panels; cleaner copy, list spacing, search alignment and more visible rows.
- Default level names follow Chinese, English and system language settings while custom names and thresholds stay unchanged.
- Switching plans fills the amount directly using the selected currency, billing cycle and exchange rate; manual prices remain editable.
- Correct product artwork and colors for ChatGPT, Google products, Figma, QQ Music and other services; preserve official colors and gradients, improve light / dark presentation, and enlarge the visible tray rabbit.
- Reduce repeated database parsing, transfers and overlapping reloads. UI snapshots omit full import receipts, and closing settings releases the import preview while preserving MCP synchronization and daily cost updates.
- Clarify that the Agent client starts the local MCP server automatically after configuration; no manual terminal command is required.

### Upgrade and installation

Upgrade from 0.0.2 via **Settings → About → Check for updates**. Install manually once when upgrading from 0.0.1. Local assets and settings are retained.

Separate macOS 12+ Apple Silicon / Intel DMGs and a Windows 10/11 x64 installer are provided. Windows downloads WebView2 if needed. macOS apps are ad-hoc signed, without Developer ID signing or Apple notarization; Windows installers are not publisher-signed. System approval may be required at first launch.
