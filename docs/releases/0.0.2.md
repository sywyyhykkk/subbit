# Subbit 0.0.2

让数字资产管理更顺手的一次更新。

- 全新「账单兔」应用图标，支持浅色、深色外观，并同步更新菜单栏图标。
- 修复浅色、深色与跟随系统外观，切换设置时可即时预览。
- 官方价格链接现在会在系统默认浏览器中打开。
- 补齐服务图标的品牌色，并统一图标底色，深色模式下也清晰可辨。
- 全新中英文日期选择器。调整开始日期或付款周期后，自动带出到期日，正确处理月末与闰年。
- 固定新增资产、编辑和设置弹窗的位置与高度，切换分类或内容时不再跳动。
- 新增资产时根据界面语言默认选择人民币或美元。
- 补齐 Cursor Pro（$20/月）、Pro+（$60/月）旧订阅选项，同时保留现行套餐并补全年付价格。已有账单金额保持不变。
- 主面板显示花销等级及计算依据。提供「订阅萌新、数字玩家、效率达人、云端收藏家、数字土豪」五个可编辑等级。
- 资产列表支持按价格、添加时间排序，可选择升序或降序。价格以当前显示币种和统计周期下的个人承担成本比较。
- 设置新增关于页面，显示版本号、作者 mango 和 GitHub 链接。macOS「About Subbit」菜单打开同一页面。
- 支持在应用内检查、下载并安装签名更新，安装完成后可一键重启。
- macOS 分别提供 Apple Silicon（arm64）与 Intel（x86_64）安装包；Windows 提供 x64 安装包。

下载与你的处理器匹配的安装包。0.0.1 尚不支持应用内更新，需手动安装一次 0.0.2；后续版本可从「设置 → 关于 → 检查更新」安装。更新保留本地资产与设置。

macOS 安装包暂未经过 Apple 开发者签名与公证；应用内更新包有独立的完整性签名。

## English

- New rabbit app and tray icons, with light, dark and system appearance support and live preview.
- Official pricing opens in your default browser. Service icons have consistent tiles and restored brand colors.
- Localized calendar with automatic expiry calculation, including month ends and leap years.
- Stable dialog positions and heights across categories and settings tabs.
- New assets default to CNY in Chinese and USD in English.
- Select legacy Cursor Pro ($20/month) and Pro+ ($60/month), alongside current plans and annual pricing. Existing bills are preserved.
- Spending level and its basis are visible on the dashboard, with five editable default levels.
- Sort by normalized personal cost or date added, ascending or descending.
- About shows the version, author mango, GitHub, and in-app signed updates with restart.
- Separate macOS Apple Silicon / Intel installers and a Windows x64 installer.

Install 0.0.2 manually once when upgrading from 0.0.1. Future releases can be installed from Settings → About → Check for updates. Local data is retained. macOS builds are not Apple-signed or notarized; updater artifacts use a separate integrity signature.
