# Subbit 0.0.6

## 修复与改进

- 修复 Windows 下打开托盘小面板后，点击「新增资产」可能导致应用卡死的问题。

已有资产和设置无需迁移。

## English

### Fixes and improvements

- Fix an application freeze when clicking Add asset in the Windows tray panel.
- Apply the same window-opening fix to Settings, Statistics and Open Subbit.

Existing assets and settings need no migration.

## 安装与升级 / Installation

- macOS 12+：Apple Silicon 与 Intel 分别下载对应 DMG；Windows 10/11 x64 使用安装 EXE。
- 0.0.2–0.0.5 可通过设置 → 关于 → 检查更新升级；0.0.1 需手动安装。离线模式下先恢复联网再检查更新。
- macOS 应用使用 ad-hoc 签名，尚未 Apple 公证；Windows 尚无发布者签名。首次下载可能出现系统信任提示，Windows 缺少 WebView2 时需要联网安装。
- macOS 12+: choose the Apple Silicon or Intel DMG; Windows 10/11 x64: use the installer EXE.
- Versions 0.0.2–0.0.5 support Settings → About → Check for updates; install manually from 0.0.1. Disable offline mode before checking.
- macOS uses ad-hoc signing without Apple notarization; Windows has no publisher signature. First downloads may show trust prompts. Missing WebView2 requires an internet connection to install.
